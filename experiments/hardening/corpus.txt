# seti) değişmez ve bu dosyanın alt kümesidir: ortak satırların repo, tag,
# commit, kapsam ve dışlamaları birebir aynı olmalıdır
# (`tests/test_hardening_corpus.py` sınar).

# Biçim (boşlukla ayrılmış):
#   ad  tür  github-deposu  tag  commit  kapsam-dizini  [ek-dışlama ...]

# Türler — metrikler kod deyimine göre saptığı için (dogfooding: typer komutları
# `too_many_params`'ı şişirdi) dağılım tür bazında da raporlanır:
#
#   library      yeniden kullanılmak üzere yazılmış paket
#   cli          son kullanıcının komut satırından çalıştırdığı araç
#   web_app      bir framework üzerinde yazılmış uygulama (Django/Flask/FastAPI)
#   ml_research  model eğitimi/çıkarımı için araştırma kodu

# black ve mypy Blok 1'de kütüphanelerle birlikte seçildi ama birincil rolleri
# komut satırı aracı olduğu için burada `cli`.
#

# config'i `tests/`, `migrations/`, `venv/`, `build/`, `dist/` dışlar; korpus
# da aynısını yapar, çünkü buradan çıkan eşik kullanıcının varsayılan
# taramasına uygulanacaktır. Ek dışlama yalnızca varsayılanın kaçırdığı
# üretilmiş ya da kopya kod içindir:
#
#   mealie  alembic    Alembic migration'ları (Django'nun migrations/'ı gibi)
#   pydantic v1        v1'in gömülü kopyası; aynı kodu iki kez sayar
#   mypy    test typeshed  mypy'nin kendi test paketi; stub kopyaları

# Tag kuralı: en son kararlı sürüm tag'i; kararlı tag yoksa (nanoGPT,
